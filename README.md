Минимальный симулятор цифровых и смешанных схем в духе Electronics Workbench. Написан на Go, интерфейс построен на [cimgui-go](https://github.com/AllenDang/cimgui-go) (Dear ImGui).

Набор компонентов ограничен тем, что нужно для лабораторных работ по электронике: операционный усилитель в режимах суммирования и дифференцирования, триггеры и счётчики, комбинационная логика (7447, 74148, 7427), сумматоры, АЛУ 74181, ЦАП и АЦП, синтез в базисе И-НЕ с Word Generator, Logic Converter и Logic Analyzer.

## Сборка и запуск

Нужны Go 1.22+ и компилятор C: cimgui-go собирается через CGO.

```
go mod tidy
go run .                 # пустая схема
go run . circuit.json    # открыть сохранённую схему
```

Тесты ядра не зависят от cimgui-go:

```
go test ./circuit ./sim ./logic
go test ./sim -bench .   # время одного кадра на схеме АЦП–ЦАП
```

## Модель

Схема моделируется в одном из двух режимов. Если на ней есть операционный усилитель или конденсатор, используется аналоговый режим: метод узловых потенциалов, конденсатор по неявной схеме Эйлера, ОУ — источник напряжения, управляемый напряжением, с коэффициентом A и насыщением на ±VSW. Цифровые элементы в этом режиме не моделируются, ключи и реле времени работают.

В остальных схемах токи не считаются: источники идеальные, приборы не нагружают цепь.

- Каждый узел хранит напряжение и силу драйвера: сильный, слабый или отсутствует.
- Земля, источники, выходы микросхем и выход ЦАП — сильные драйверы. Два сильных драйвера с разным напряжением на одном узле отображаются как `SHORT CIRCUIT`.
- Батарея и генераторы задают разность потенциалов `V(+) − V(−) = E`. Значения распространяются по графу от узлов с известным напряжением.
- Резистор и подтяжка — слабая связь: узел без сильного драйвера получает напряжение с другой стороны резистора. Делитель напряжения в такой модели не работает.
- Узел без драйвера считается плавающим. Логический вход читает его как 1 (как у ТТЛ), пробник как 0.
- Порог логической единицы — 2,5 В. Логические выходы выдают 5 В или 0 В.
- Задержки вентилей нулевые. На каждом шаге по времени комбинационная логика приводится к устойчивому состоянию, затем срабатывают элементы, управляемые фронтом, и цикл повторяется, пока ничего не меняется.

Формулы и соглашения:

- **ЦАП:** `Vout = V(−) + (V(+) − V(−)) · code / 256`.
- **АЦП:** при переходе SOC из 1 в 0 `code = floor(256 · (Vin − VREF−) / (VREF+ − VREF−))`, результат ограничен диапазоном 0…255. EOC опускается в 0 на 1 мкс, выходы активны при OE = 1, иначе отключены.
- **ЦАП:** неподключённые и отключённые входы читаются как 0.
- **74181:** таблица функций для активно-высоких данных, уровни на выводах берутся как есть. CN = 0 означает перенос на входе, CN+4 = 0 — перенос на выходе.
- **74148:** входы и выходы активно-низкие, приоритет у старшего входа, EI = 1 запрещает работу.
- **7447:** выходы активно-низкие. LT', RBI' и BI'/RBO' работают по даташиту, для кодов 10–15 выводятся символы из даташита.
- **RS-триггер:** при S' = R' = 0 оба выхода равны 1. Если после этого оба входа одновременно перевести в 1, триггер принимает случайное состояние.

## Управление

- **Палитра (Parts):** кнопка выбирает компонент, щелчок по холсту ставит его.
- **Провода:** щелчок по выводу, затем по другому выводу. Щелчок по пустому месту во время прокладки ставит точку соединения и продолжает провод от неё. Точку соединения можно перетащить; щелчок по ней без перетаскивания начинает от неё новый провод.
- **Выделение и удаление:** щелчок выделяет деталь или провод, перетаскивание двигает деталь, Delete или Backspace удаляет выделенное. Точки соединения, у которых не осталось проводов, удаляются вместе с ним.
- **Отмена:** Esc или правая кнопка.
- **Вид:** перетаскивание правой или средней кнопкой сдвигает холст, колесо меняет масштаб. `H` или кнопка Hand включает и выключает режим руки: в нём левая кнопка сдвигает холст и не меняет схему.
- **Панели:** вертикальные разделители по бокам от схемы перетаскиваются мышью. Если сузить панель почти до нуля, она скрывается; чтобы вернуть её, разделитель тянут обратно.
- **Реле времени:** COM соединён с A с момента TON до TOFF (мс), в остальное время с B.
- **Ключи:** переключаются своей клавишей (`Space`, `A`–`Z` кроме `H`, `0`–`9`, `Enter`) или кнопкой Toggle в панели свойств.
- **Свойства:** значения применяются по Enter. Изменение свойства, влияющего на модель, перезапускает симуляцию. Настройки приборов (развёртка, В/дел, частоты) меняются без перезапуска.
- **Simulation:** Run/Pause, Reset, сохранение и загрузка JSON. `step, us` — шаг по времени, `sim ms / frame` — сколько модельного времени проходит за один кадр. Оба значения сохраняются в файл схемы.
- **Провода по состоянию:** красный — 1, синий — 0, серый — узел плавает.

Интерфейс собран в одном окне: сверху панель Simulation, слева палитра, в центре схема, справа свойства выделенной детали и вкладки приборов. Щелчок по прибору на схеме открывает его вкладку:

- **Oscilloscope:** два канала, вход G — общий провод. Курсоры T1 и T2 показывают время и напряжения.
- **Word generator:** 16 выходов, режимы Cycle, Burst, Step и Stop; слова задаются в шестнадцатеричном виде, кнопки `Count N bits` заполняют счётную последовательность.
- **Logic converter:** `Circuit -> Table` строит таблицу истинности схемы, подключённой к входам A… и выходу OUT (A — старший разряд); генераторы слов на время анализа отключаются. `Table -> Simplified` даёт минимальную ДНФ в формате Multisim (`AB'+C`). Таблицу можно редактировать вручную, значения 0/1/x.
- **Logic analyzer:** 16 каналов с выборкой на внутренней частоте, курсоры T1 и T2.

Шестнадцатеричный индикатор по умолчанию рисует цифры сегментами. Кнопка `Segments / matrix` в панели свойств переключает его на матрицу 5×7 прямо во время симуляции; выбор сохраняется в файле схемы.

## Структура

```
circuit/   модель схемы, JSON, каталог компонентов и их выводов
sim/       ядро симуляции, модели устройств и приборов, тесты по данным лабораторных
logic/     минимизация Квайна–Мак-Класки с точным покрытием
ui/        редактор и панели приборов на cimgui-go
circuits/  готовые схемы лабораторных и практических работ (см. circuits/README.md)
main.go    окно GLFW
```
